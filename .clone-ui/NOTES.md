# 视频复刻与验证记录

输入为用户提供的 `docs/brief.txt` 和 1472×1080、6.367 秒桌面参考录像。属于提供素材的复刻：录像与截图可以确认视觉结构及动作，无法取得源页面 DOM 或逐项计算样式。

## 已实现与修正

完整保留 Hero → Marquee → About → Services → Projects 顺序、提供的文字和项目资料。图片与字体本地化。人物磁吸、双排反向滚动、逐字显现、渐显和 sticky 卡片缩放均以实际浏览器数值验证。

独立视觉复核指出两项明确差异，已修正：桌面四角装饰物放大约 20%；Live Project 从约 207×56 调至接近参考的 243×67。还根据录像调整标题字距、首屏人物比例、三行介绍、服务内容宽度、区块间距及项目标题布局。

## 验证阶段

- A 内容与素材：五个区块、五项服务、三个项目和 63 个重复图片槽均存在。文案来自用户初稿，原图片存在性在浏览器中检查。
- B 样式：使用初稿的黑底、银灰渐变、Kanit 字体与原按钮渐变；实际截图核对尺寸和位置。源 DOM 缺失，无法执行源页面计算样式的逐项一致性证明。
- C 视觉与交互：320、390、768、1472、1920px 五种宽度检查，截图在 `artifacts/`；自动验证反向位移、文字透明度、sticky/缩放、磁吸、表单与键盘操作。
- D 独立复核：确认两项视觉尺寸差异，已按证据修正。没有报告额外明确功能缺陷。
- E 差异与经验：本文件记录限制，具体经验见 `lessons.md`。

TypeScript 与 Vite 生产构建通过。运行 `python scripts/verify-browser.py` 可以重新生成完整验证结果 `artifacts/verification.json`。运行 `npm audit --omit=dev` 时，生产依赖未发现已知漏洞。Tailwind 3 的开发依赖审计仍有上游 advisories，未擅自切换初稿指定的大版本。

## 已知差异与限制

- Celestia 原链接返回 404，以用户提供的 Luminex 动图填补该槽，保留 21 个槽与三次重复。其他图片保留原素材。
- GIF 缩为实际展示尺寸 420×270，使用 128 色调色板和 15 fps，总量从约 168 MB 降至 67.1 MB。细部颜色、帧时刻可能与录像不同。
- 录像没有手机布局，窄屏依据初稿响应式要求调整，无法证明与源手机页面一致。
- 录像未展示点击后行为，附件未提供邮箱与实际项目地址。联系按钮生成可复制的咨询草稿；项目按钮打开原项目图库，可在数据中填写 liveUrl 接入真实网站。
- 文案保持按词换行，避免录像中部分单词在字符间断行；逐字显现保留。
- 静态截图的磁吸位置、GIF 帧与文字显现程度受鼠标、时间及滚动位置影响。未宣称逐像素一致。

## 2026-10-14 — 按录像复核装饰物的可见轮廓

**Smell**：文字规格中的图片宽度与录像看起来一致，但透明素材的实际轮廓偏小。
**Failure**：直接采用 210px 容器宽度，月亮和 LEGO 的可见轮廓比参考约小 17%。
**Truth**：录像中月亮可见宽度约 163px，LEGO 约 204px。
**Mitigation**：用参考截图和实际截图比较透明内容轮廓；桌面宽度提高 20%，保留手机、平板已有布局。

## 2026-10-14 — 录像中的按钮尺寸优先于文字初稿

**Smell**：按初稿的字体和 padding 实现胶囊，形态接近但视觉重量偏小。
**Failure**：Live Project 为约 207×56，录像约 243×67。
**Truth**：桌面项目按钮需要约 20px 字体及更大 padding。
**Mitigation**：以浏览器实际边界和参考帧为依据调整桌面规则，复核 320–1920px 的布局。

## 2026-10-14 — 咨询草稿标签与剪贴板的 Windows 验证

**Smell**：生成内容放在嵌套 label 的 textarea 中，自动化无法按精确标签定位。
**Failure**：正文会参与 Playwright 的 label 文本匹配；剪贴板逐字比较又因 Windows CRLF 产生误报。
**Truth**：显式 htmlFor/id 保持标签与内容分离，系统剪贴板可能规范化换行。
**Mitigation**：草稿使用独立关联标签；验证复制内容时只规范化 CRLF，再比较全部消息。
